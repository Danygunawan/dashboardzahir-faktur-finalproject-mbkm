Zahir Invoice OCR — demo Deployment Aplikasi
==========================================

Demo web lokal tiga layar, Home/Data, tema, dan unduhan Excel/CSV.

Mulai dari `README-DEMO.md <README-DEMO.md>`_ untuk instalasi dari salinan bersih,
ruang lingkup CI tanpa OCR, serta penyiapan model untuk ekstraksi sebenarnya.

Data pelanggan, outputs, model, dan virtual environment tidak termasuk sumber demo.
Tidak ada push atau deployment otomatis dalam workflow CI.
