# Zahir Invoice OCR — versi demo

Versi demo yang disiapkan untuk penilaian Deployment Aplikasi adalah web lokal
tiga layar: Pilih Dokumen → Atur Konversi → Hasil, dengan Home/Data, tema, serta
unduhan XLSX dua sheet atau ZIP dua CSV. Tampilan dan mesin ekstraksi dipertahankan.

Dokumentasi instalasi: [docs/INSTALL.md](docs/INSTALL.md).
Ruang lingkup dan status CI: [docs/CI.md](docs/CI.md).
Pemeriksaan sebelum push/deployment: [docs/REVIEW-BEFORE-PUSH.md](docs/REVIEW-BEFORE-PUSH.md).

Workflow yang ditambahkan hanya menjalankan tes. Belum ada CI repositori yang
terbukti berjalan sampai workflow benar-benar dipicu pada repositori tujuan.
Tidak ada langkah push atau deployment otomatis.
